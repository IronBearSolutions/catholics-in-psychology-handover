# Catholics in Psychology — website handover

Download **catholics-in-psychology-website.zip** from this repository. This is the complete static website, prepared on 3 November 2026 with the approved Montserrat font and softer sage-green palette.

## Upload to your own Netlify account

1. Download the website ZIP and extract it on your computer.
2. Open the extracted folder. It must contain **index.html** and an **assets** folder beside it.
3. Sign in to your Netlify account and use its manual drag-and-drop deployment area.
4. Upload the whole extracted folder containing **index.html** and **assets** together. No build command, programming tools or separate asset connections are required.
5. Open the new Netlify URL and check Home, About, Events and Register your interest.

The existing Google Form link remains in the website. Hosting this website does not grant access to the form's responses; the form owner manages those permissions separately.

This public repository is a standalone handover location. It is separate from LED Guide and does not change the current live Netlify website or connect to automatic deployment.
